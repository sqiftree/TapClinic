## 1. Kuesioner SUS 10-Butir (Adaptasi Bahasa Indonesia)

Diisi oleh partisipan segera setelah menyelesaikan masing-masing varian (Varian A dan Varian B).  
Skala Likert 5-poin: **1 = Sangat Tidak Setuju (STS)**, **2 = Tidak Setuju**, **3 = Netral**, **4 = Setuju**, **5 = Sangat Setuju (SS)**.

| No | Pernyataan | Polaritas |
| :---: | :--- | :---: |
| 1 | Saya rasa saya akan sering menggunakan sistem ini. | Positif |
| 2 | Saya merasa sistem ini terlalu rumit tanpa alasan yang jelas. | Negatif |
| 3 | Saya merasa sistem ini mudah digunakan. | Positif |
| 4 | Saya rasa saya memerlukan bantuan orang teknis untuk dapat menggunakan sistem ini. | Negatif |
| 5 | Saya menemukan bahwa berbagai fungsi dalam sistem ini terintegrasi dengan baik. | Positif |
| 6 | Saya rasa terlalu banyak ketidakkonsistenan dalam sistem ini. | Negatif |
| 7 | Saya membayangkan kebanyakan orang akan belajar menggunakan sistem ini dengan sangat cepat. | Positif |
| 8 | Saya merasa sistem ini sangat canggung/membingungkan saat digunakan. | Negatif |
| 9 | Saya merasa sangat percaya diri saat menggunakan sistem ini. | Positif |
| 10 | Saya perlu mempelajari banyak hal terlebih dahulu sebelum dapat menggunakan sistem ini. | Negatif |

### Rumus Perhitungan Skor SUS (Brooke, 1996)
- Untuk butir ganjil (1, 3, 5, 7, 9): $\text{kontribusi}_i = x_i - 1$
- Untuk butir genap (2, 4, 6, 8, 10): $\text{kontribusi}_i = 5 - x_i$
- Skor total: $\text{SUS} = 2{,}5 \times \sum_{i=1}^{10} \text{kontribusi}_i$ (rentang **0 hingga 100**; **bukan** persentase keberhasilan tugas).

### Acuan Interpretasi Skor (Bangor dkk., 2008; Lewis & Sauro, 2018)
- **≥ 80,3**: *Excellent* (Grade A)
- **68,0 – 80,2**: *Good* (Di atas rata-rata industri 68)
- **51,0 – 67,9**: *OK / Marginal* (Perlu perbaikan signifikan)
- **< 51,0**: *Poor* (Tidak layak adopsi)

## 2. Cek Singkat Literasi Kesehatan (3 Butir)

Terinspirasi dari 3 butir literasi kesehatan yang digunakan Albrink dkk. (2024) dari instrumen HLS-GER 2 (bukan keseluruhan HLS-EU-Q16). Skala: **1 = Sangat Sulit**, **2 = Cukup Sulit**, **3 = Cukup Mudah**, **4 = Sangat Mudah**.

1. Seberapa mudah Anda memahami penjelasan dokter atau tenaga medis tentang kondisi kesehatan Anda?
2. Seberapa mudah Anda menemukan informasi mengenai gejala penyakit yang sedang dialami?
3. Seberapa mudah Anda menilai kapan perlu segera pergi ke klinik saat sakit?
